📻 Sobre o Projeto
O Craque do PB é uma aplicação web desenvolvida para rastrear, armazenar e analisar os votos do quadro "Craque do Programa" da Rádio Atlântida. Diariamente, os integrantes da bancada votam no destaque da edição. Este projeto visa transformar esses dados em insights divertidos, revelando tendências, maiores vencedores e, principalmente, quem vota em quem.

🚀 Funcionalidades
Dashboard em Tempo Real: Visualização do vencedor da última edição (13h ou 18h).
Matriz de Votação: Sistema para registrar individualmente o voto de cada integrante.
Detector de "Panelinha": Gráficos de fluxo que mostram a tendência de voto de cada membro (ex: "Quantas vezes o Arthur votou no Potter?").
Rankings: Tabelas de maiores vencedores mensais e gerais.
Estatísticas Avançadas: Métricas como "O Injustiçado" (mais votos recebidos sem ganhar o título).

🛠️ Tecnologias Utilizadas
Frontend: React, Tailwind CSS, Shadcn UI
Backend/Database: Supabase (PostgreSQL)
Data Visualization: Recharts
